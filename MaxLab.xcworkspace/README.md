# App Lab workspace

Open `MaxLab.xcworkspace` in Xcode. The shared workspace exposes the independent Gamefy, Reset and MaxLab projects while preserving their separate repositories and schemes. Select `Gamefy`, `Reset` or `MaxLab` in the scheme menu and run on an iPhone Simulator or signed iPhone.

Foundation is included as a reference package for browsing generic reusable code. New products should copy the foundation template into their own repository rather than adding product code here.
